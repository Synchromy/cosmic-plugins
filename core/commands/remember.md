Save this fact to the person's Cosmic: $ARGUMENTS

1. Work out which person, company or project it is about. If that is not clear, ask before saving.
2. Call `remember` with the fact, that entity, and where it came from (this conversation, today's date).
3. Say whether Cosmic confirmed the save, and on which page. A refusal is not a save; say so and why.

Never save passwords, sign-in codes, tokens, card details, or anything the person marked confidential.
